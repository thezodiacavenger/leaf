# Leaf test harnesses

These scripts verified every feature during development. Each runs inside Electron so the real
engine, hidden windows (darkroom, workroom, renderer) and `leaf://` protocol are exercised.

Run one (Linux needs a virtual display; on Windows drop `xvfb-run -a`):

```bash
xvfb-run -a npx electron --no-sandbox tests/e2e/l3test.js
```

Before running, replace `/path/to/leaf-test-data` in the script with a folder holding the test files.
Scripts that `require('/home/user/leaf/...')` expect the repo at that path; adjust if yours differs.

| Script | Covers |
|---|---|
| `droptest.js` | Drag-and-drop reaches the app; empty drops explain themselves |
| `closetest.js` | Closing the gallery never crashes ("Object has been destroyed") |
| `gallerytest.js` | Gallery: arrows, Space full screen, I info sheet, Esc |
| `heic-e2e.js`, `heic-engine.js` | HEIC zip → JPEG/PNG/PDF/unzip |
| `rawtest.js`, `rawe2e.js`, `etdbg.js` | RAW extraction/develop for 8 brands, Photo info, ExifTool in Electron |
| `mailtest.js` | .msg / winmail.dat parsing and email → PDF rendering |
| `pdftest.js` | Combine + bookmarks, flatten, compress, extract, split, rotate, protect/unlock, scrub |
| `l3test.js` | Whole documents layer through suggestions → actions (OCR engine mocked off Windows) |
| `piletest.js` | First-run Leaf Pile offer, folder watcher, no echo on own output |
| `engine2.js`, `plancheck.js` | Zip/TIFF engine checks; what Leaf suggests for a given drop |

## Test data (not stored here: large and/or third-party)
- **RAW samples:** `get-raw-samples.sh` downloads one public-domain file per brand from raw.pixls.us.
- **Outlook .msg samples:** `MsgReaderTests/SampleFiles/*.msg` from github.com/kenjiuno/msgreader (via cdn.jsdelivr.net/gh/…).
- **winmail.dat samples:** `tests/files/datafiles/*.tnef` from github.com/verdammelt/tnef.
- **HEIC samples:** github.com/alexcorvi/heic2any `demo/*.heic`.
- Forms, scans, CSV and fax TIFF were generated by the scripts themselves (pdf-lib / PIL).

`build/scripts/` holds the generators for the app icon, the Leaf Pile folder icon and the desktop mock-up screenshots (they use Playwright).
